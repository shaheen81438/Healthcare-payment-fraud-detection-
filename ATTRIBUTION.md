# Attribution

MedIntegrity AI is an independently maintained extension of the MIT-licensed
`healthcare-payment-integrity` reference repository:

<https://github.com/FaridoonFarahi/healthcare-payment-integrity>

The original MIT license and copyright notice are preserved in [LICENSE](LICENSE).
The project retains and adapts the upstream data pipeline, synthetic claim
generator, temporal feature engineering, model training/evaluation pipeline,
FastAPI service, monitoring utilities, and Streamlit dashboard structure.

Original MedIntegrity AI contributions in this working tree include the
payment-integrity rules engine, provider anomaly service, LEIE screening service,
availability-aware risk aggregation, focused tests, documentation, and dashboard
sections added for those workflows. This repository does not claim that every
component was written from scratch.
